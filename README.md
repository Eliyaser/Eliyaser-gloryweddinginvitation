# Eliyaser & Glory — Interactive Wedding Invitation

A responsive Bootstrap 5 wedding invitation website based on the supplied invitation design.

## Included
- Animated invitation-opening screen
- Responsive Bootstrap navigation
- Invitation artwork from the supplied design
- Scroll reveal animations
- Live countdown to 28 November 2026, 5:00 PM IST
- Interactive OpenStreetMap map
- Google Maps directions button
- Current public-transit route cards around Jacob Gardens / Padappai
- Copy-address button
- Native share button
- WhatsApp RSVP message generator

## Run locally
Open `index.html` directly, or use a local server for best browser behavior:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Main files
- `index.html` — website
- `assets/invitation.png` — invitation artwork
